# Contributing to Google Maps Lead Generator

Thank you for considering contributing to **Google Maps Lead Generator**!

---

## Code of Conduct

Please maintain a polite, welcoming, and constructive atmosphere in all discussions and pull requests.

---

## How Can I Contribute?

### 1. Reporting Bugs
- Use the **Bug Report** template under `.github/ISSUE_TEMPLATE/bug_report.md`.
- Include your OS, Python version, error traceback logs, and steps to reproduce.

### 2. Suggesting Enhancements
- Use the **Feature Request** template under `.github/ISSUE_TEMPLATE/feature_request.md`.
- Explain why the enhancement would be valuable and describe the proposed behavior.

### 3. Pull Requests
1. Fork the repository.
2. Create a feature branch: `git checkout -b feature/my-new-feature`.
3. Keep code changes modular and ensure existing fallback selectors remain functional.
4. Test changes locally: `python lead_generator.py`.
5. Submit a Pull Request targeting the `main` branch.

---

## Code Style & Guidelines

- Follow PEP 8 guidelines where appropriate.
- Keep dependencies minimal to retain lightweight execution.
- Maintain atomic write patterns for file updates to prevent corruption.
